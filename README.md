# Myanmar Bible App

A mobile-first Myanmar-language Bible reading PWA prototype.

## Development
```bash
npm install
npm run dev
```

## Current status
- Warm earth-tone responsive reader UI
- Burmese Padauk font
- Book and chapter navigation prototype
- Sample-only scripture content (not an authorized Bible text)
- Local UI interactions for highlights, notes, theme and search

## Important
Replace sample scripture content only with a Bible translation and digital text that has explicit permission for app distribution, offline storage, search, and sharing.
